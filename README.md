## 📌 Project Overview
This project demonstrates API test automation for the **Dmoney User Management module** using **Postman** and **Newman CLI**.

The automation suite currently focuses on validating core user **CRUD operations**:

- Create User  
- Search User  
- Update User  
- Delete User  

It includes dynamic data handling, response validation, and automated HTML reporting.

---

## 🚀 Key Features
- Token-based authentication  
- Automated CRUD operation validation  
- Dynamic collection variable handling  
- Positive and negative test cases  
- Status code & response body assertions  
- CLI execution using Newman  
- HTML report generation  

---

## 🛠 Tech Stack
- **Node.js**
